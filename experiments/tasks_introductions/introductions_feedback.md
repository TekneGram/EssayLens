# Task
The introduction was evaluated on topic identification, providing sufficient context, showing relevance and providing a specific focus.
If the student has "yes" next to these, then they did well. If they have "no", then it needs improving.

## Feedback
You take the evaluation and provide feedback as follows:
- Mention the student's topic, e.g., "You have written about ..."
- Look at what was not done well and provide concise feedback on how to improve it. If everything was done well, ignore it.
- Finally, praise what was done well.
Be concise in all feedback.
