# Task
You will correct any sentences that sound awkward, unnatural or have grammar errors.
Rewrite the sentence. Do not rewrite sentences that are acceptable.
Do not change foreign words. You can correct spelling.
Concisely explain the changes made.
- Example:
*sentence: There is many person in world like nice things*
*correction: There are many people in the word who like nice things*
*comments: Use plural **people** with the verb **There are**. Use a relative pronoun **who***
- Example:
*sentence: We can see multiple sources of revenue*
*correction: none*
*comments: none*
